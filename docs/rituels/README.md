# Rituels Off the Map

Les événements Scrum n’existent pas dans GitHub : ils ne sont visibles que si on les écrit. Ce dossier contient les notes de l’équipe, versionnées avec le code.

| Fichier | Contenu | Qui l’écrit |
| --- | --- | --- |
| `sprint-goal.md` | l’objectif du sprint | PO, confirmé au planning |
| `sprint-planning.md` | capacité, charges, estimations confirmées, engagement | PO, rempli par l’équipe au planning |
| `definition-of-done.md` | quand une issue est terminée | PO, relue par l’équipe |
| `scrum-masters.md` | rota du Scrum Master du jour | PO |
| `daily/Jx.md` | une note de 5 lignes par jour | Scrum Master du jour |
| `retro/Jx.md` | rétrospective de fin de journée : fait, prévu, obstacles | Scrum Master du jour |
| `review.md` | démonstration et retours | Scrum Master du dernier jour |
| `retrospective.md` | à garder, à arrêter, une action | toute l’équipe |

Le « tableau » cité dans les notes est le kanban du projet GitHub « OffTheMap » (https://github.com/users/CamillePaillou/projects/2). Les échanges du quotidien (commandes à lancer, migration à appliquer après une fusion) passent par Discord ; aucune décision n'y est prise : elles sont écrites ici, dans les issues ou dans les PR.

Copier `daily/_modele.md` en `daily/J1.md`, `J2.md`, etc. Le daily se tient le matin ; le bilan du soir va dans `retro/Jx.md`.
